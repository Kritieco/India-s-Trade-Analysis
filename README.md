# India Export Analysis (2010–2021)

Analysis of India's export trade data across 184,000+ records 
covering HS commodity codes and partner countries.

## Tools Used
Python, pandas, matplotlib, seaborn, scikit-learn

## Key Findings
 USA is India's largest export market (14.7% share)
 Mineral fuels and pearls are top exported commodities
 Exports forecast to reach 363,959 USD Million by 2024
